# AI SHIFT LIVE — Vercel version

Полноценная live-игра для семинара: ведущий создаёт сессию, команды подключаются одновременно, ответы оцениваются автоматически.

## Что нужно для реальной многопользовательской работы

1. **Upstash Redis** (бесплатного тарифа достаточно для семинара): создайте Redis database и добавьте в Vercel:
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`

2. **OpenAI API** — необязательно. Без него игра работает и ставит DEMO-оценки. Для реальной AI-оценки добавьте:
   - `OPENAI_API_KEY`
   - `OPENAI_MODEL=gpt-5.6-luna` (или другую доступную вам модель)

## Развёртывание на Vercel

### Самый простой путь
1. Распакуйте архив.
2. Создайте новый GitHub-репозиторий и загрузите содержимое папки.
3. В Vercel выберите **Add New → Project → Import Git Repository**.
4. Framework Vercel определит как Next.js автоматически.
5. Добавьте переменные окружения из `.env.example`.
6. Нажмите Deploy.

После деплоя одна ссылка используется всеми:
- ведущий открывает `/host`;
- команды открывают `/team`.

## Логика игры
- Раунд 1: 90 секунд, 3 риска + причинная логика.
- Раунд 2: 75 секунд, кризис + решение + ответственность + компромисс + критерий пересмотра.
- Раунд 3: 90 секунд, 3 защитных правила + объяснение системы.
- AI-оценка: 0–10 за каждый раунд; максимум 30.

## Важно
Vercel serverless не подходит для хранения общей live-сессии только «в памяти», поэтому Redis нужен именно для одновременной работы нескольких телефонов/ноутбуков.
