# AI SHIFT LIVE — Vercel version

Live-игра для семинара: ведущий создаёт сессию, команды подключаются одновременно, проходят 3 раунда, а ответы автоматически оцениваются по прозрачной экспертной рубрике 0–10.

## Что нужно

Только **Upstash Redis** (бесплатного тарифа достаточно для семинара). В Vercel нужны:
- `UPSTASH_REDIS_REST_URL`
- `UPSTASH_REDIS_REST_TOKEN`

OpenAI API и платные AI-ключи не используются.

## Логика игры

- Раунд 1: 90 секунд — 3 риска + причинно-следственная логика.
- Раунд 2: 75 секунд — кризис + решение + ответственность + компромисс + критерий пересмотра.
- Раунд 3: 90 секунд — 3 защитных правила + объяснение системы.
- За каждый раунд: 0–10 баллов, сильная сторона, слепая зона, вывод и рекомендация.
- В конце: рейтинг /30 и общий вывод по аудитории.

## Как считается оценка

Оценивание детерминированное и одинаковое для всех команд. Оно учитывает структуру аргумента, связь с выбранными рисками/правилами, конкретность, ответственность, компромиссы, критерии пересмотра, системность и реализуемость. На экране команды показывается разбивка баллов по критериям.

## Развёртывание

Vercel + Next.js. Redis нужен для общей live-сессии на нескольких телефонах/ноутбуках.
